# 无名树 · 家长端小程序高保真原型

为"无名树"这类自然教育家长社群设计的家长端小程序原型（v0.1），纯静态 HTML 实现，无需构建。

**在线预览**：<https://zhumin2.github.io/wumingshu-prototype/>

## 包含页面

| 页面 | 覆盖场景 |
|---|---|
| 首页 | 季节活动横幅、快捷入口、活动卡片（报名中 / 候补 / 预约中） |
| 活动详情 | 装备清单、流程时间线、费用（扣课时）、报名入口 |
| 报名弹层 | 多孩选择、电子知情同意、提交后缴费提醒 |
| 相册 | 按"我家孩子"筛选照片（本原型的差异化功能） |
| 成长档案 | 多孩切换、老师观察笔记时间线、成长手册预告 |
| 我的 | 课时包、孩子过敏史与紧急联系人、照片授权 |

## 交互提示

- 底部标签切换页面；点活动卡片进详情；点"立即报名"看报名弹层
- 相册页可切换"全部 / 只看小树"筛选
- 支持深色模式（跟随系统）

## 设计说明

- 目标用户：自然教育 / 研学类家长社群的组织者与家长
- MVP 三件套：报名缴费（事前）→ 照片分发（事中）→ 成长档案（长期）
- 页面数据均为虚构演示数据
