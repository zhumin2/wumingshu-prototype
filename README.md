# 无名树 · 家长端小程序

为"无名树"这类自然教育家长社群设计的家长端产品。仓库同时包含**高保真 HTML 原型**和**可运行的微信小程序工程**。

- 🎨 在线原型预览：<https://zhumin2.github.io/wumingshu-prototype/>
- 📱 小程序工程：`miniprogram/`（微信开发者工具直接导入即可运行）

## 产品定位

社群的运营流程目前散落在公众号推文、群接龙、群收款和群相册里。这个 App 把它们搬进结构化流程，核心就三件事：

| 阶段 | 解决的问题 |
|---|---|
| 事前 · 报名缴费 | 名额/候补/退费/多孩代报，替代群接龙人肉统计 |
| 事中 · 照片分发 | 几百张活动照按孩子精准分发，家长只看得到自家孩子 |
| 长期 · 成长档案 | 老师观察记录 + 照片沉淀为成长手册，驱动续费与转介绍 |

**明确不做**：即时通讯、内容 feed、原生 App（家长不会为单个社群再装一个 App，小程序是唯一正确入口）。

## 小程序工程结构

```
wumingshu/
├── project.config.json          # 微信开发者工具工程配置
├── miniprogram/
│   ├── app.js / app.json / app.wxss
│   ├── sitemap.json
│   ├── data/mock.js             # 演示数据（全部虚构，真实版本替换为后端接口）
│   ├── custom-tab-bar/          # 自定义 tabBar（emoji 图标，无需图片资源）
│   └── pages/
│       ├── home/                # 首页：季节横幅、快捷入口、活动卡片
│       ├── detail/              # 活动详情 + 报名弹层（多孩选择/知情同意/提交）
│       ├── photos/              # 相册：按"我家孩子"筛选（差异化功能）
│       ├── growth/              # 成长档案：多孩切换、观察笔记、成长手册
│       └── profile/             # 我的：课时包、孩子健康信息、报名记录
└── index.html                   # 高保真 HTML 原型（GitHub Pages 入口）
```

### 本地运行

1. 微信开发者工具 → 导入项目 → 选择本仓库根目录
2. AppID 选「测试号」即可（`project.config.json` 中为 `touristappid`）
3. 编译运行。无需 npm 安装、无构建步骤

### 已实现的交互

- 自定义 tabBar 四页切换，选中态同步
- 首页活动卡片 → 详情页（携带 `id` 动态渲染三场不同活动）
- 详情页报名弹层：多孩勾选、合计金额实时计算、必填校验、提交后写入 `wx.setStorageSync`
- 报名成功后「我的」页「我的报名」列表即时出现（含候补状态区分）
- 相册页「全部 / 只看小树」筛选
- 成长档案多孩切换，展示不同孩子的徽章与观察笔记
- 详情页支持 `open-type="share"` 转发

### 技术选择说明

- **原生小程序**而非 Taro/uni-app：MVP 只有 5 个页面，原生零构建、启动快、调试直接
- **emoji 图标**：保持活跃的自然风视觉，省去切图和 CDN 依赖，后续可替换为 iconfont
- **设计变量集中在 `app.wxss`**：一套 token 控制全站配色，改主色只需改一处

## 后续迭代建议

1. 接入后端（活动/报名/支付/相册），替换 `data/mock.js`
2. 照片按孩子自动归类（人脸聚类需本地化处理，儿童数据合规是底线）
3. 组织者端：发布活动、实时名单、缴费核对
4. 成长手册生成与 PDF 导出（增值付费点）
